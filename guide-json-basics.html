JSON 是什么？从对象、数组到字符串转义

最后更新：2026 年 8 月

JSON 是一种非常常见的数据交换格式。它的优势不是“看起来像代码”，而是结构简单、文本可读，并且很容易被不同语言解析。

对象：用键和值描述一组数据

JSON 对象使用大括号包围，并用键值对表达信息。例如一个用户对象可以包含 name、age 等字段。键名和字符串值使用双引号，这是 JSON 与某些编程语言对象字面量容易混淆的地方。

数组：保存有顺序的一组值

数组使用方括号，可以包含多个字符串、数字、对象或其他数组。对象和数组可以嵌套，因此 JSON 可以表达比较复杂的数据结构。

JSON 支持哪些基本值

  • 字符串：使用双引号。
  • 数字：可以是整数或带小数的数字。
  • true / false：布尔值，不需要引号。
  • null：表示空值。
  • 对象和数组：用于组合更复杂的数据。

为什么 JSON 里不能随便写单引号

严格 JSON 要求字符串使用双引号。如果把键名写成单引号形式，很多 JSON 解析器都会直接报错。类似地，末尾多一个逗号也可能导致整个文档无法通过严格校验。

什么时候需要格式化

接口返回的 JSON 经常是一整行压缩文本，阅读起来很困难。格式化会增加缩进和换行，但不会改变数据本身。相反，压缩会去掉多余的空白，让文本更紧凑。

本地处理有什么好处

如果只是格式化公开配置或普通示例，在浏览器中完成解析可以减少数据上传的需要。不过“本地运行”不等于“任何数据都可以放心粘贴”。敏感数据仍然应该优先在可信环境中处理。

可以直接使用JSON 格式化与校验工具验证一段 JSON，并对照错误信息检查语法。

结语

理解 JSON 的关键只有几个：对象用大括号，数组用方括号，字符串使用双引号，布尔值和 null 不加引号。掌握这些规则后，大多数日常 JSON 错误都可以快速定位。
