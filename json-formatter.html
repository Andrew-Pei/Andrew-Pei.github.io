JSON 格式化与校验

粘贴 JSON 后进行格式化、压缩或语法校验。核心处理在浏览器本地完成，适合快速检查接口示例、公开配置和开发中的 JSON 文本。

这个工具能回答什么？
它能判断输入是否能被浏览器的 JSON 解析器读取，并在合法时把数据重新序列化为更易阅读或更紧凑的形式。它不能判断字段是不是符合某个 API 的业务要求，因此“JSON 语法正确”不等于“接口一定接受”。
最常见的报错来源
  • 键名或字符串使用了单引号。
  • 对象或数组最后留下了尾逗号。
  • 相邻元素之间漏写逗号。
  • 大括号、方括号或双引号没有配对。
  • 把 true、false、null 写成了字符串。
为什么格式化有用？
压缩 JSON 往往只有一行，嵌套层级不明显。格式化会增加缩进和换行，使对象、数组和字段层级更容易检查。这个过程改变的是空白排版，不是数据结构本身。
一个推荐的排错顺序
先读解析器提示的位置，再检查外层括号、双引号、逗号和嵌套结构；语法通过后，再回到接口文档检查字段类型、必填字段和业务约束。不要把语法错误和业务错误混在一起。

安全提醒
不要因为工具在浏览器本地运行，就把生产环境密钥、私钥、认证令牌等高度敏感内容随意粘贴到网页。设备安全、浏览器扩展和页面本身都可能成为风险来源。
